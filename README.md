# مترجم الألعاب (Game Translator)

تطبيق لتلفزيون أندرويد / Google TV / Fire TV. تصوّر شاشة اللعبة بكاميرا الآيفون، والتطبيق يقرأ النص ويترجمه للعربي بـ Google Translate، ويعرض الترجمة فوق الشاشة في التلفزيون وفي الجوال. يشتغل مع أي مصدر للعبة، حتى بلايستيشن أو إكسبوكس موصولة بـ HDMI.

## رابط التحميل الثابت

```
https://github.com/<اسم-حسابك>/game-translator/releases/latest/download/GameTranslator.apk
```

كل مرة ترفع فيها تعديل، GitHub يبني نسخة جديدة على نفس الرابط، وكود Downloader يبقى نفسه.

## التثبيت على التلفزيون

1. افتح Downloader واكتب الكود.
2. ثبّت التطبيق (إذا طلب، فعّل "تثبيت تطبيقات غير معروفة" لتطبيق Downloader).
3. افتح "مترجم الألعاب" واضغط "السماح بالظهور فوق الشاشة" وفعّل الخيار.
   - إذا التلفزيون ما فيه هالشاشة، فعّله من الكمبيوتر بالأمر:
     `adb shell appops set com.gametranslator.tv SYSTEM_ALERT_WINDOW allow`
   - وبدون هالإذن الترجمة تشتغل عادي، بس تطلع في الجوال بس.

## الاستخدام من الآيفون

1. خلّ الجوال والتلفزيون على نفس الواي فاي.
2. امسح الباركود اللي في شاشة التطبيق بكاميرا الآيفون، وافتح الرابط في سفاري.
3. (اختياري) من سفاري: زر المشاركة ← "إضافة إلى الشاشة الرئيسية" عشان تصير مثل التطبيق.
4. اضغط "صوّر شاشة اللعبة"، صوّر الكلام، والترجمة تطلع.
5. بعدها ارجع للعبة، والمترجم يظل شغّال في الخلفية.

## ملاحظات

- قراءة النص تدعم اللغات اللي تنكتب بالحروف اللاتينية (الإنجليزي، الفرنسي، الإسباني، الألماني...). الياباني والصيني والكوري يبي لها إضافة.
- الترجمة تحتاج إنترنت في التلفزيون.
